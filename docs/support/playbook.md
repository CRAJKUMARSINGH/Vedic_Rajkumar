# Support Playbook

## Channels

- In-app feedback widget → PostHog
- support@ inbox → shared ticketing
- Discord community

## SLA

| Priority       | First response  |
| -------------- | --------------- |
| P1 (can't use) | 2h              |
| P2 (bug)       | 1 business day  |
| P3 (question)  | 2 business days |

## Feedback → roadmap

Weekly: tag feedback, cluster themes, top 3 themes become roadmap candidates.
Close the loop: reply when shipped.
