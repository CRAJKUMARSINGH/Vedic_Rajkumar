# SEO Playbook

## Programmatic pages

- `/rashi/:sign` — 12 pages
- `/nakshatra/:name` — 27 pages
- `/panchang/:date` — daily, indexable
- `/transit/:graha/:sign` — computed pages

## Requirements per page

- [ ] Unique `<title>` + meta description
- [ ] JSON-LD (Article / FAQ)
- [ ] Canonical URL
- [ ] Internal links to related pages
- [ ] sitemap.xml regenerated on deploy
- [ ] OG image (auto-generated)

## Core Web Vitals

Keep LCP < 2.5s on all landing pages or rankings suffer.
