The rationale

Most astrology software is a black box.

You enter a birth time and get a verdict — no ayanamsa, no longitudes, no way to see whether the maths is right. Vedic Rajkumar starts from the opposite idea: a tradition built on careful observation of the sky deserves software you can inspect.

  1. I

    Show the work

    Graha longitudes, house cusps, ayanamsa value and nakshatra padas sit beside every chart. You can check the arithmetic instead of trusting a verdict.

  2. II

    Prove the numbers

    A 15-chart adversarial corpus is compared with the Swiss Ephemeris on every change. If accuracy slips, the build fails.

  3. III

    Meet people where they are

    Full English and Hindi with correct Devanagari. Works offline after first load. No account needed to cast a chart.

  4. IV

    Keep it open

    MIT-licensed, readable TypeScript engines. Fork it, audit it, or switch on Swiss Ephemeris for research-grade precision.

Accuracy, measured

Precision is a claim. So we test it.

The engine is checked against the Swiss Ephemeris on a corpus picked to break it — odd timezones, historic clock changes and the edges of the map. Continuous integration blocks any change that makes a chart less accurate.

Run it yourself

Your first chart in under two minutes.

No database and no API keys — demo mode runs entirely in the browser. Add login and saved readings later if you need them.

  • TypeScript strict
  • React 18
  • Vite 7
  • Tailwind CSS 4
  • Radix / shadcn
  • TanStack Query
  • jsPDF
  • swisseph-wasm
  • Vitest
  • Playwright
  • Netlify
terminal
$ git clone https://github.com/CRAJKUMARSINGH/Vedic_Rajkumar.git
$ cd Vedic_Rajkumar
$ cp .env.example .env   # all optional
$ npm install
$ npm run dev   # → localhost:5173

Needs Node ≥ 22. Set VITE_USE_SWISS_EPHEMERIS=true for research-grade precision.
